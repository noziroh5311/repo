두 판 연결

홈페이지의 ‘두 판’ 구조를 그대로 옮겼다. 라이트는 시안 1의 조간판(신문 지면), 다크는 시안 2의 야간판(작업대) — 같은 웹하드가 밝을 땐 신문, 어두울 땐 작업대가 된다. 사이드바 아래에 지금 판의 이름을 찍고, 로고는 한 장의 SVG 안에 두 판을 모두 담아 같은 자리의 붉은 잉크 네모가 밤에는 파란 커서가 된다.

  • 두 세계, 한 파일custom.css 한 장에 :root:not(.dark) 조간판, :root.dark 야간판.
  • 판 표시사이드바 버전 문구 위에 ‘조간판 · MORNING’ / ‘야간판 · NIGHT’.
  • 한 장의 로고logo.svg 가 OS 다크 설정을 따라 스스로 판을 바꾼다.
  • 전환 = OS 설정브랜딩 테마 ‘시스템 기본값’이면 OS 다크 모드를 따라 판이 갈린다.

손댈 주요 선택자

선택자바꾸는 것
:root:not(.dark) …시안 1 규칙 전부. File Browser 는 라이트일 때 html 에 .light 를 붙이거나 비워 두므로 :not(.dark) 로 잡는다
:root.dark …시안 2 규칙 전부 (모눈 배경·패널·등폭·눈금 선택·커서)
nav p.credits::before판 이름 표시 — 판마다 글꼴·문구가 다르다
#login h1::after조간판: 제호 아래 붉은 부제 / 야간판: 블록 커서
img/logo.svg 내부 <style>@media (prefers-color-scheme: dark) 로 .day / .night 그룹 전환

글꼴

  • 조간판: Bodoni Moda + Noto Serif KR
  • 야간판: JetBrains Mono + Noto Sans KR
  • 네 글꼴을 모두 불러오므로 첫 로딩이 시안 1·2보다 무겁다. 쓰지 않는 판의 글꼴도 @import 로는 함께 받는다(미검증: 브라우저가 쓰이지 않는 글꼴 파일은 실제로 받지 않을 가능성이 높다).

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경에서 열리지 않았다(프록시가 접속 거부, 403). 두 테마는 직접 보지 못했고 작업지시서의 토큰 표로만 판단했다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 판 전환은 File Browser 의 테마를 따른다. 소스(frontend/src/utils/theme.ts)를 보면 브랜딩 테마가 비어 있으면(‘시스템 기본값’) 페이지를 열 때 OS 의 prefers-color-scheme 으로 light/dark 를 정한다. 열어 둔 채 OS 설정을 바꾸면 새로고침해야 바뀐다. 홈페이지처럼 헤더의 해·달 버튼은 File Browser 에 없으므로 그릴 수 없다.
  • logo.svg 는 <img> 로 들어가므로 File Browser 의 .dark 클래스가 아니라 OS 설정을 따른다. 테마를 ‘시스템 기본값’으로 두면 둘이 일치하고, 설정에서 테마를 강제로 고정하면 어긋날 수 있다. (이 목업의 토글은 로고 변형본을 바꿔 끼워 보여 준다.)
