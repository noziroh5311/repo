야간판 계승

kwonmo.com 다크(소스맵·게임리스트·대항해 화면)를 웹하드로 옮겼다. 로고는 홈 헤더와 같은 JetBrains Mono 의 ‘KWONMO’, 헤더 아래엔 ‘지금 탭’ 파란 밑줄, 경로는 페이지 제목처럼 4px 회색 괘선 위에 등폭 글꼴로. 목록은 둥근 패널 한 장, 선택한 줄은 소스맵에서 고른 상자처럼 밝게 채운다. 격자 보기는 게임 카드처럼 종류마다 테두리 색이 다르고 오른쪽 위에 확장자 꼬리표(WIN·DOS 자리)가 붙는다. 라이트는 같은 구조에 색만 밝힌 ‘주간 작업대’.

  • 등폭 제호logo.svg 는 JetBrains Mono 글자 윤곽선. 파비콘은 K + 파란 밑줄.
  • 페이지 제목경로는 등폭 굵은 글자, 아래 4px 회색 괘선(‘게임리스트’ 제목과 같다).
  • 밝은 선택선택 줄은 #d9dee7 채움 + 어두운 글자 — 소스맵의 고른 상자.
  • 종류별 테두리폴더 파랑·사진 청록·PDF 주홍·압축 황토·영상 보라, 확장자 꼬리표 attr(data-ext).

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경의 네트워크 허용 목록에 없어 직접 열지 못했다. 대신 사용자가 준 스크린샷(조간판: 홈·작품·편집기 / 야간판: 소스맵·게임리스트·대항해)과 작업지시서 토큰 표로 맞췄다. 색 값은 토큰 표 그대로이고, 스크린샷에서 읽은 것은 모양(괘선·카드·제목·로고 글꼴)이다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 주간 작업대(라이트)는 kwonmo.com 에 없는 조합이다. 홈페이지 라이트(조간판)와 맞추려면 시안 3.
  • 작업지시서엔 ‘격자 느낌’이 있었지만 받은 스크린샷의 다크 화면엔 모눈 배경이 없어 넣지 않았다(카드 격자로 해석).
  • 확장자 꼬리표는 data-ext 값을 그대로 쓰므로 ‘.JPG’처럼 점이 붙는다. 점을 빼려면 확장자마다 규칙을 따로 써야 한다.
  • color-mix() 는 2023년 이후 브라우저에서만 된다. 오래된 브라우저에선 테두리가 순정 색으로 남는다.
