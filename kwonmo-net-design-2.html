야간판 계승

kwonmo.com 다크의 작업대를 웹하드로 옮겼다. 바탕에 24px 모눈을 깔고, 파일 목록은 모서리가 둥근 패널 한 장, 경로는 꺾쇠 대신 ‘/’로 이어 등폭 글꼴로 쓴다. 선택한 줄은 색을 뒤집지 않고 파란 기운과 왼쪽 눈금만 준다. 라이트는 같은 작업대에 낮 조명을 켠 ‘주간 작업대’ — 구조는 그대로, 색만 밝다.

  • 모눈 바탕본문·로그인 바탕에 24px 격자. 화면 요소는 그 위에 놓인 패널.
  • 등폭 정보경로·크기·날짜·사용자명은 JetBrains Mono, 본문은 Noto Sans KR.
  • 눈금 선택선택 줄은 옅은 파랑 + 왼쪽 3px 눈금. 아이콘·이름만 파랗게.
  • 깜빡이는 커서로그인 제목 끝에 파란 블록 커서(@keyframes).

글꼴

  • JetBrains Mono — 사용자명·경로·크기·날짜·로그인 제목 (Google Fonts, OFL)
  • Noto Sans KR — 본문, 그리고 등폭 글꼴 안의 한글 대체 (Google Fonts, OFL)
  • Material Icons — 순정 그대로

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경에서 열리지 않았다(프록시가 접속 거부, 403). 두 테마는 직접 보지 못했고 작업지시서의 토큰 표로만 판단했다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 주간 작업대(라이트)는 kwonmo.com 에 없는 조합이다. 홈페이지 라이트(조간판)와 맞추려면 시안 3.
  • 등폭 글꼴엔 한글이 없어 한글 파일명은 Noto Sans KR 로 내려간다. 영문·숫자만 등폭으로 정렬된다.
