웹하드 · 시스템

2차 시안의 웹하드 뼈대는 그대로, 야간판을 ‘시스템’으로 밀었다. 바탕엔 점 격자, 도구줄 위엔 파란 신호선, 경로는 PATH 와 ‘/’로 잇는 시스템 경로, 목록 줄 끝엔 형식 꼬리표(DIR·.JPG·.PDF…)를 종류색으로, 고른 줄은 빛나는 테두리. 격자 보기는 모서리 표시만 남긴 HUD 칸, 저장 공간은 칸으로 끊긴 STORAGE 계기, 계정엔 접속 표시등, 로그인은 AUTH 단말. 글꼴은 등폭(JetBrains Mono)을 앞에 세웠다. 업로드 단추·만들기 칸·저장 공간 카드·주소 표시줄·끌어다 놓는 빈 폴더는 두 판 공통.

  • 점 격자 · 신호선본문·로그인 바탕 16px 점 격자, 헤더 위 2px 파란 그라데이션.
  • 형식 꼬리표attr(data-ext) 를 줄 끝에, 폴더는 DIR. 색은 파일 종류색.
  • HUD 칸격자 칸은 테두리 없이 네 모서리 표시만(그라데이션 8겹). 고르면 파랗게.
  • 계기 · 표시등STORAGE 칸 막대, 계정 옆 초록 접속 표시등, AUTH 로그인 단말.

  • Noto Sans KR — 화면 전체
  • JetBrains Mono — 주간은 숫자(크기·날짜·번호)만, 야간은 메뉴·경로·이름·표 머리줄까지
  • 로고 글자 — 주간 Noto Sans Bold, 야간 JetBrains Mono (윤곽선으로 굳힘)
  • Material Icons — 순정. 체크 배지·업로드/보관함 아이콘도 같은 글꼴의 합자

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경의 네트워크 허용 목록에 없어 직접 열지 못했다. 대신 사용자가 준 스크린샷(조간판: 홈·작품·편집기 / 야간판: 소스맵·게임리스트·대항해)과 작업지시서 토큰 표로 맞췄다. 색 값은 토큰 표 그대로이고, 스크린샷에서 읽은 것은 모양(괘선·카드·제목·로고 글꼴)이다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • custom.css 는 한 장이다. 주간·야간 페이지는 같은 CSS 의 두 판이고, 판마다 다른 규칙은 :root:not(.dark) / :root.dark 아래에 묶여 있다.
  • logo.svg 는 판마다 다른 두 장이다. File Browser 에는 한 장만 넣을 수 있으므로, 둘 다 쓰려면 1차 시안 3처럼 위아래로 쌓은 스프라이트 + object-position 으로 합쳐야 한다.
  • :has() 는 Chrome 105·Safari 15.4·Firefox 121 이후에서만 된다. 그 전 브라우저에선 빈 폴더가 순정 모양으로 보인다(기능은 같다).
  • 업로드 단추 글자는 데스크톱 헤더에서만 보인다. 폰 폭에선 동작 단추들이 ‘더보기’ 메뉴로 옮겨 간다(미검증: 메뉴 안 모양).
  • 주간 문서 대장 번호는 지금 정렬 순서의 순번이다. 정렬을 바꾸면 번호도 바뀐다.
  • 야간 ‘접속 중’ 표시등은 로그인 상태를 뜻할 뿐 실제 서버 상태를 읽지 않는다(CSS 장식).
