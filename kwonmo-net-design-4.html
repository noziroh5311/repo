자유안 · 서고

홈페이지가 ‘신문’이라면 웹하드는 그 신문을 철해 두는 ‘서고’다. 짙은 녹색 간판에 황동 선, 목록은 카드함 — 한 줄이 색인 카드 한 장이고, 폴더는 서가 번호, 파일은 문서 번호를 CSS 카운터로 찍는다. 선택한 줄은 반쯤 꺼낸 카드처럼 옆으로 밀려 나온다. 격자는 보존 상자, 사진은 매트 액자, 로그인은 열람 카드.

  • 청구기호CSS counter 로 ‘서가 01’, ‘No.04’를 이름 앞에. 마크업 추가 없음.
  • 꺼낸 카드선택 줄은 황동 테두리 + 그림자 + 오른쪽으로 0.9em 이동.
  • 보존 상자 · 액자격자 보기 상자 뚜껑 띠, 사진 보기 매트 여백과 아래 캡션.
  • 열람 카드로그인 폼에 붉은 머리선·괘선·아래 구멍 (그라데이션 세 겹).

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경의 네트워크 허용 목록에 없어 직접 열지 못했다. 대신 사용자가 준 스크린샷(조간판: 홈·작품·편집기 / 야간판: 소스맵·게임리스트·대항해)과 작업지시서 토큰 표로 맞췄다. 색 값은 토큰 표 그대로이고, 스크린샷에서 읽은 것은 모양(괘선·카드·제목·로고 글꼴)이다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 청구기호는 고정 ID 가 아니라 ‘지금 화면의 순번’이다. 정렬을 바꾸면 번호도 바뀐다.
  • 선택 줄은 translateX 로 밀고 같은 만큼 폭을 줄인다. 격자 보기에서는 폭을 줄이지 않으므로 상자가 오른쪽으로 0.9em 비어져 나온다(의도).
  • 목록 보기에서 File Browser 가 여러 개 선택(Shift/Ctrl) 상태일 때도 같은 스타일이 줄마다 적용된다 — 여러 장이 동시에 꺼내진 모양.
