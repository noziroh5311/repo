조간판 계승

kwonmo.com 라이트의 신문 지면을 그대로 웹하드로 옮겼다. 종이색 바탕에 먹색 글자, 제호 아래 이중 괘선, 목록은 지면의 표처럼 괘선으로 나누고, 선택한 줄은 붉은 잉크로 뒤집어 찍는다. 다크는 별도 세계관을 만들지 않고 같은 지면을 검은 종이에 인쇄한 ‘흑지판’으로 처리했다.

  • 이중 괘선헤더 하단 1px + 3px 간격 + 4px. 경로줄·목록 머리에도 먹선.
  • 붉은 잉크 선택선택 줄은 붉은 바탕에 종이색 글자. 아이콘은 먹·적 2도.
  • 세리프 지면Bodoni Moda 제호, Noto Serif KR 본문. 숫자는 고정폭 숫자.
  • 사진 = 보도사진사진 보기에서 살짝 바랜 톤, 그라데이션 대신 사진 아래 캡션.

글꼴

  • Bodoni Moda — 제호·경로·소제목 (Google Fonts, OFL)
  • Noto Serif KR — 본문 전체 (Google Fonts, OFL). 한글 세리프라 첫 로딩이 무겁다(가변 글꼴 분할 로딩).
  • Material Icons — 순정 그대로

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경에서 열리지 않았다(프록시가 접속 거부, 403). 두 테마는 직접 보지 못했고 작업지시서의 토큰 표로만 판단했다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 흑지판(다크)은 kwonmo.com 에 없는 조합이다. 홈페이지와 다크를 맞추고 싶다면 시안 3이 그 답이다.
