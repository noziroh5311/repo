조간판 계승

kwonmo.com 라이트의 신문 지면을 웹하드로 옮겼다. 로고는 홈 제호와 같은 Bodoni Moda 의 ‘KWONMO’, 그 아래 굵은 괘선과 얇은 괘선을 겹쳐 긋고, 바탕엔 종이 결을 깔았다. 경로는 지면 제목처럼 4px 먹선 위에, 격자 보기 소제목은 홈 사이드바의 붉은 꼭지(글자 + 가는 붉은 선), 카드는 작품 목록처럼 둥근 모서리. 다크는 같은 지면을 검은 종이에 찍은 ‘흑지판’.

  • Bodoni 제호logo.svg 는 Bodoni Moda(작은 크기용 opsz 11) 글자 윤곽선. 파비콘은 같은 글꼴의 K.
  • 홈과 같은 괘선헤더 아래 굵은 4px → 3px 간격 → 얇은 1px. 경로 아래 4px 먹선.
  • 붉은 꼭지격자 보기 ‘폴더/파일’을 자간 넓은 붉은 글자 + 가는 붉은 선으로.
  • 종이 결 · 카드SVG 노이즈 바탕, 둥근 카드와 붉은 채움 버튼은 작품 페이지에서.

확인되지 않은 점 · 주의

  • kwonmo.com 은 이 작업 환경의 네트워크 허용 목록에 없어 직접 열지 못했다. 대신 사용자가 준 스크린샷(조간판: 홈·작품·편집기 / 야간판: 소스맵·게임리스트·대항해)과 작업지시서 토큰 표로 맞췄다. 색 값은 토큰 표 그대로이고, 스크린샷에서 읽은 것은 모양(괘선·카드·제목·로고 글꼴)이다.
  • 화면은 File Browser v2.63.23 소스(Vue 템플릿·CSS)를 읽고 같은 클래스·id 구조로 다시 그린 목업이다. 실제 인스턴스에 custom.css 를 넣어 본 것은 아니므로 실물과 간격·크기가 조금 다를 수 있다(미검증).
  • 디스크 사용 막대(.vue-simple-progress, -bar)는 색·높이가 인라인 style 로 들어가므로 !important 가 필요하다.
  • ::before/::after 의 content 로 붙인 문구는 CSS 만으로 가능하지만 번역·스크린리더 대상이 아니다.
  • 흑지판(다크)은 kwonmo.com 에 없는 조합이다. 홈페이지와 다크를 맞추고 싶다면 시안 3이 그 답이다.
  • 로그인 제목(인스턴스 이름)은 제호 아래 붉은 꼭지로 작게 쓴다. 이름을 ‘kwonmo.net’ 으로 바꿔 두는 것을 전제로 했다.
